
# NinjaPhonetics

Deterministic Acoustic Biofeedback & Biomechanical Coaching for Japanese English Learners.

Unlike black-box pronunciation apps that only output vague accuracy scores, NinjaPhonetics visualizes physical acoustic targets (Formant convergence, Spectral Center of Gravity, 2D Vowel Spaces) via Plotly and translates acoustic deviations into concrete, anatomical articulatory cues (e.g., upper-molar lateral tongue anchoring) powered by LLMs.

|                           | **B2. /f/ vs /v/** (*fan* vs *van*)                          | **高**     | **◎ 必須**       | **無声音区間のパワー比** ＋ **F0（有声性）**                 | ・破裂音（[b], [p]）化していないか（急峻なバーストの有無）。 ・母音開始前の純粋な摩擦音区間の持続。 | 下唇を噛むのではなく、「**下唇の内側（濡れている境界部分）を上前歯の先端に軽く当てて**、隙間から息を漏らす」。 |
|                           | **B3. /θ, ð/ の過剰調音** (挟みすぎてリズムを破壊)           | **中**     | ◯                | **摩擦区間の持続時間（Duration）** ＋ **後続母音の立ち上がり** | ・/θ/ の摩擦区間が **規定ミリ秒（例: 80〜100 ms）を超えて過剰に長くないか**。 ・後続母音への移行ラグ。 | 舌を上下前歯で挟むのをやめさせ、「**上前歯の先端の裏に舌先を軽く触れさせるだけ（スリットを作るだけ）**」の脱力指導。 |
|                           | **B4. 語頭 /h/ の摩擦不足** (気流の弱さ)                     | **低**     | △                | **気息音区間の高周波エネルギー** ＋ **母音前の無声長**       | ・母音開始前の無声声門摩擦ノイズ（Glottal Friction）のエネルギーが十分か。 | 「寒い日に手のひらを温めるときのように、喉の奥からしっかりと暖かい息を吐き出す」。 |
| **C. 鼻音系**             | **C1. 語尾の鼻音の欠落・曖昧化** (日本語の「ん」化)          | **低**     | △                | **鼻音ホルマント（Nasal Murmur）** ＋ **口腔閉鎖の持続**     | ・語尾の有声鼻腔共鳴（〜250 Hz周辺の低周波エネルギー）の明瞭さと閉鎖の完了度。 | 舌先（/n/）、両唇（/m/）、軟口蓋（/ŋ/）で息の出口を完全に密閉する意識付け。 |
|                           | **C2. /ŋ/ の徹底** (*sing* vs *sin*)                         | **低**     | △                | **反共鳴（ゼロ点）** ＋ **$F_2, F_3$ 結合部（Velar Pinch）** | ・後続に破裂音 [ɡ] を出さず、軟口蓋閉鎖のまま鼻腔に抜けているか。 | 「『鼻濁音のガ行（かがみ、などの鼻に抜けるガ）』を言う直前のポジションで声を鼻に通す」。 |
| **D. 破裂音・閉鎖音系**   | **D1. 語尾破裂音の母音付加** (*cat-o*, *good-o* などのカタカナ化) | **最高**   | ◯ (意識で修正可) | **RMSエネルギー** ＋ **基本周波数（F0）の残存**              | ・子音閉鎖・破裂バースト後の **有声母音エネルギー（F0および母音ホルマント）の残存時間（> 20 msでNG）**。 | 「音を綺麗に終わらせようとせず、息をピタッと止める（舌先や唇で呼気を密閉ブロックする）」感覚を徹底。 |
|                           | **D2. /t/ の異音バリエーション** (Flap / Glottal Stop / Unreleased) | **高**     | ◯ (意識で修正可) | **閉鎖時間（Closure）** ＋ **バースト形状・有声性**          | ・Flap [ɾ]: 15〜30 msの極短有声閉鎖。 ・Glottal Stop [ʔ]: 声帯の急峻な切断と無音（バーストなし）。 ・Unreleased [t̚]: バーストのない閉鎖終端。 | *water*, *get it*, *button* など個別の単語コンテクストに応じた「舌先の脱力タッピング」や「喉の奥での息止め」。 |

|                           | **E3. ア・オ系母音の区別** (*hat* / *hot* / *hut* / *caught* 等) [/æ/ vs /ɑː, ɑ/ vs /ʌ/ vs /ɔː, ɔ/] | **高**     | **◎ 必須**       | **$F_1 - F_2$ 散布図** (話者内正規化)                        | ・*hat* (/æ/): 高 $F_1$ ＋ 高 $F_2$（開・前舌）。 ・*hot* (/ɑ/): 高 $F_1$ ＋ 低 $F_2$（開・後舌）。 ・*hut* (/ʌ/): 中 $F_1$ ＋ 中 $F_2$（半開・中後舌）。 ・*caught* (/ɔ/): 中 $F_1$ ＋ 低 $F_2$（円唇・後舌）。 | ・*hat*: 「指2本縦に入るくらいアゴを落とし、口角を横に引く」。 ・*hot*: 「あくびのように喉を広げ、アとオの中間」。 ・*hut*: 「口を開けず、お腹を叩かれたときの脱力した短いア」。 ・*caught*: 「口を縦に開け、唇を丸め気味に保つ」。 |
