## 💡 コンセプトと開発思想：確率論的AIジャッジから「決定論的ストライクゾーン」へ

市販の英語発音アプリの多くは、ディープラーニングによる統計モデルを用いて「78点」「Good!」といったブラックボックスなスコアを返す設計になっています。しかし、運動学習（Motor Learning）の観点から見ると、これらは「結果の通知（Knowledge of Results）」に過ぎず、**「口腔内のどこがどう物理的にズレており、舌や唇をどう動かせば良いのか」という身体操作（Knowledge of Performance）の処方箋**が得られません。

NinjaPhonetics が目指したのは、**野球の「ストライクゾーン」**です。

ピッチャーが投球練習をするとき、「今の球は62点」と言われるよりも、「外角高めに3インチ外れた」とボールの通過ゾーンが見えるからこそ、次の1球で指先のリリースや体重移動を微調整できます。

発音も全く同じです。
声道の幾何学的形状と音響物理は1対1で直結しています。  
「舌の側面を上顎の奥歯に密着させ、舌根を引く」という調音操作を行えば、物理法則に従って **$F_3$ が急降下し、$F_2$ との差分 $\Delta(F_3 - F_2)$ が $1000\,\text{Hz}$ 未満のストライクゾーンに必ず吸い込まれます**。

母国語特有の干渉パターンごとに「最も効く物理指標」を選び抜き、直感的なバイオフィードバック計器として提供することで、誰でも迷わず最短でネイティブの調音ターゲットに到達できるようにします。

## 🛠️ 主な機能とUI設計（Biofeedback Scope）

1. **3段連動オシロスコープ（プロフェッショナル・ダーク計器）**
   * **第1段（Waveform）**: 生波形（振幅エンベロープ）。無音区間、子音破裂パルス、音節の長さを視認。末尾（`-ly` や `-y` 等）の減衰を削らない適応型時間マージン設計。
   * **第2段（$F_2 \text{ and } F_3$ ホルマント）**: 青（$F_3$）と緑（$F_2$）の軌跡。周波数上限を $4000\,\text{Hz}$ まで拡張し、高域の共鳴抜けを完全にカバー。
   * **第3段（$\Delta(F_3 - F_2)$ 差分 & Rストライクゾーン）**: $0\sim 1000\,\text{Hz}$ の帯域全体を **半透明の赤色シェードパッチ（R STRIKE ZONE）** として可視化。黄色いトレースがこのゾーンに潜り込んでいるかを一目で直感判別。
2. **広帯域スペクトログラム背景**
   * 音声の時間–周波数解析が表示されます。
   * LPC（Burg法）によるトラッキング誤認や線の乱れが生じた際も、物理的な共鳴エネルギー帯（白い光帯）で真のホルマントを確認可能。
   * ツールバーの `Spectrogram: ON/OFF` ボタンで瞬時に表示切替が可能。
3. **高機能オーディオ & 計測操作**
   * **ピッチ維持タイムストレッチ再生**: HTML5 `preservesPitch` 機構を採用し、0.7x や 0.5x のスロー再生時でも音程（ピッチ・ホルマント）を変えずに肉声を再生。
   * **お手本自動再生**: お手本プリセット選択から1秒後に自動で再生がスタート。
   * **ドラッグ選択 & 縦カーソル連動**: 注目したい子音・母音区間をドラッグ選択して反復試聴。可動赤色カーソルで任意の位置のミリ秒単位の物理周波数（$F_3, F_2, \Delta$）をリードアウト表示。
   * **ワンクリック・エクスポート**: 表示中の解析プロットを画像（`PNG`）として、音声を非圧縮WAV（`WAV`）として即座にダウンロード可能。

## 🚀 ローカルでのセットアップ・実行方法

Bash

```
git clone [https://github.com/](https://github.com/)<your-username>/ninja-phonics.git
cd ninja-phonics

# 仮想環境の作成と有効化
python3 -m venv .venv
source .venv/bin/activate
```

## 🗺️ 今後のロードマップ（課題別可視化ツールの展開）

母国語の音韻体系に応じて、適切な物理指標・表示形式を段階的に追加予定です。

- [ ] **B2 強化: f-v-b-h 摩擦・破裂鑑別スコープ**:
  - 立ち上がり時間（Rise Time）による破裂（/b/）vs 摩擦（/v, f, h/）の自動識別
  - 低域（$< 250\,\text{Hz}$）の Voice Bar エネルギー比率による有声（/v, b/）vs 無声（/f, h/）判定
  - $0\sim 8000\,\text{Hz}$ 全帯域スペクトログラムにおける母音共鳴の透け具合による /f/（唇歯摩擦ノイズ）vs /h/（声門通過・声道共鳴ノイズ）の視覚分離
- [ ] **B1 対策**: `/si/` vs `/ʃi/`（高域スペクトル重心 COG 分析・$5\sim 8\,\text{kHz}$ 歯擦音スコープ）
- [ ] **E2 対策**: 強弱リズム・母音長比（モーラ拍からストレス拍への移行・持続時間比チェッカー）
- [ ] **E3 対策**: ア・オ系母音（hat / hot / hut / caught）の $F_1-F_2$ 2D母音マップ
- [ ] **Gemini API 連携**: 差分値・持続時間などの物理特徴量から、完全無料枠で身体的処方箋（アドバイス）を自動生成するリアルタイムコーチング機能

| | **E5. 二重母音の一般ルール** (/aɪ/, /eɪ/, /aʊ/ 等) | **中** | △ | **ホルマント移行長・比率** ($F_1, F_2$ の遷移速度) | ・第1要素（長く強く）と第2要素（短く弱く）の **持続時間・エネルギー減衰勾配**。 | 「日本語の『アイ』のように2音並べるのではなく、前半をしっかり出して後半は添えるだけ」。 |

| | **E7. 三重母音** (*fire*, *power* 等) | **低** | △ | **ホルマント軌跡の3点推移** | ・中央の要素の弱化・平滑化（Smoothing）の度合い。 | 「3つの母音を律儀に言おうとせず、中央を軽くかすめて滑らかに抜ける」。 |
| **F. 連鎖・プロソディ系** | **F1. リンキング・リダクション** (*I got to know about it.*) | **中** | △ (知識で解決) | **音節境界のエネルギー谷** (Valley Depth) | ・単語境界での急激な音圧低下（不要なポーズ・息継ぎ）がないか。<br>・音響的連続性。 | 理屈の解説が主。「個別の単語を発音し直すのではなく、1つの長い単語として息を止めずに一息で言い切る」。 |
| | **F2. イントネーション・ピッチ輪郭** (文末核音調／Declination) | **中** | △ (方言差大) | **基本周波数（F0）輪郭** ＋ ピッチ傾斜勾配（st/s） | ・平叙文末の急降下（Final Fall）、疑問文末の急上昇（Final Rise）。<br>※米英豪など主要方言間で正解輪郭が大きく乖離し、また意味弁別上クリティカルでないためストライクゾーン対象外。 | 「日本語のように語尾をフラットや中途半端な高さで放置せず、文末で思い切って音程を一段落とす」。 |
